# MP2RAGE_Volume_Processor

Generate qT1 volume from MP2RAGE T1-weighted UNI.

Generate associated volumes:
- B1-corrected T1-weighted UNI,
- Synthetic EDGE,
- Synthetic FLAWS,
- and their denoised version.
Generate T1-weighted UNI denoised volume (not B1-corrected).

Provides the range for which the qT1 volume is valid.

Makes coffee and asks about your day.
